Política de privacidade

Esta página explica como são tratados os dados de quem visita este site, de acordo com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018).

Quem é o responsável

Rafael Machado, corretor de imóveis, CRECI-DF 31465, Brasília/DF. Contato: WhatsApp (61) 99547-2902.

Quais dados são coletados

  • Dados que você envia ao iniciar uma conversa pelo WhatsApp, como nome, telefone e informações sobre o seu imóvel.
  • Se você aceitar os cookies, dados de navegação coletados pelo Pixel da Meta (páginas visitadas e cliques), usados para medir e melhorar os anúncios.

Para que são usados

Para responder ao seu contato, prestar o serviço de intermediação imobiliária e medir o desempenho dos anúncios. Os dados não são vendidos a terceiros.

Com quem são compartilhados

Com ferramentas usadas no atendimento (WhatsApp, sistema de gestão de clientes) e, se você aceitar os cookies, com a Meta Platforms para mensuração de anúncios.

Seus direitos

Você pode pedir a qualquer momento acesso, correção ou exclusão dos seus dados, ou retirar o consentimento dos cookies, pelo mesmo WhatsApp acima.
